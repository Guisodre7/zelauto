# assets/

Marca da ZelAuto usada pelo console (`admin/`), pela landing (`site/`), pelo app
e pelo favicon.

- `zelauto-logo.svg` — versão vetorial da marca (funciona já, em qualquer tamanho).

**Para usar a arte exata (PNG):** salve o arquivo como `zelauto-logo.png` nesta
pasta. Onde a referência aponta para o `.svg`, troque para `.png` (ou use o PNG
direto). O SVG é o padrão porque não depende de nenhum upload e escala sem perder
qualidade.
